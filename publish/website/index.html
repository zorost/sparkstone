Local AI, struck from stone.

Sparkstone runs Thinking Machines’ Inkling 2 Mini at native NVFP4 on the NVIDIA DGX Spark on your desk, with more open models to follow. It ports the Basalt inference engine to GB10, and it can put two Sparks behind one endpoint.

View on GitHub Get started

What it is

The engine behind the "Inkling 2 Mini at 613 tok/s on one RTX 5090" results only ran on x86 PCs with an RTX 50-series card. Sparkstone brings it to the DGX Spark's Grace Blackwell chip without rewriting a kernel.

GB10 native

Every NVFP4 and FP8 kernel is built for sm_121, and the host builds for Arm. Five small patches, offered upstream.

128 GB, one address space

No spilling experts over a PCIe bus. The GPU reads the whole model and a 1M-token context in unified memory.

Proven, then published

A one-command self-test runs the GPU parity suite and the community benchmark on your own Spark.

Where it stands

We only publish numbers we have measured. These rows are kept up to date.

✓ Builds for GB10All 45 GPU code objects target sm_121; block-scaled FP4 tensor-core instructions assemble for sm_121a.
✓ Runs on ArmBasalt's CPU test suite passes 78/78 on AArch64. One upstream race the port exposed is fixed.
✓ Twin routerTwo Sparks, one OpenAI/Anthropic-compatible endpoint, conversation affinity, failover.
● On hardwareGPU parity, quality and speed on DGX Spark: in progress. Projected 37–59 tok/s chat and 91–145 tok/s structured output, single stream.

Sparkstone Twin

Cable two Sparks together and serve them as one machine: double the throughput and double the context pool, with conversation-aware routing that keeps each chat on the Spark holding its cache. Splitting each token across both Sparks over the 200 GbE link comes next, once our link-latency measurements show it pays off.

Get started

On a DGX Spark with DGX OS 7 and CUDA 13:

git clone https://github.com/zorost/sparkstone && cd sparkstone
scripts/spark-preflight.sh
scripts/build-spark.sh
scripts/download-model.sh
scripts/serve-spark.sh          # OpenAI + Anthropic API on :8080

FULL=1 scripts/selftest.sh      # full hardware report

Need it running across a fleet, air-gapped, or tuned for your models? Talk to Zoros.
